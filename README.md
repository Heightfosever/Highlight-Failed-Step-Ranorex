**A.** No. Only 64-bit Windows editions can run this build.

**Q.** I need a place to unpack. What sort of directory is acceptable?

**A.** Pick any directory your account can write in, and stay clear of protected system directories.

# The short version

All files created by the archive go away when the extracted folder is deleted.

Running `setup` is how the Windows build in this archive starts. Pull the files out before that.

To use this program, extract the contents of the zip archive to a folder of your choice. Once extracted, open the folder and run the file named `setup` to start the program.

# Known issues

- **Setup opens and closes right away.** Start it from a Command Prompt in the same folder. The console keeps the message that was closing with the window.
- **Windows rejected the path as too long.** Choose a place nearer the drive root and extract there.
- **Folder protection blocked the write.** Permit `setup` on the Controlled Folder Access list. Unpacking into a folder Windows trusts already is the other route.
- **An extra folder is sitting in between.** The inner directory holds them together. Open it and `setup` is there with the other files.
- **Files may be lost during extraction.** To avoid losing your files, make sure to copy them to a different location before extracting a new archive into the same folder.
